# Лабораторная работа № 2

**Дисциплина:** Эволюционное программирование и генетические алгоритмы  
**Вариант:** 19  
**Задача:** построение расписания экзаменов с конфликтами студентов

## Что находится в проекте

- `ga_schedule.py` — основная реализация генетического алгоритма. Здесь находятся загрузка данных, расчёт целевой функции, турнирная селекция, два кроссовера, мутация, repair, формирование нового поколения и запуск алгоритма.
- `experiments.py` — серия экспериментов. Запускает методы на 20 разных seed, сохраняет результаты в CSV и строит графики.
- `generate_data.py` — генерация синтетических входных данных с фиксированным seed.
- `data/exams.csv` — список экзаменов.
- `data/student_exams.csv` — какие экзамены сдаёт каждый студент.
- `data/generation_info.txt` — параметры генерации данных.
- `results/parameters.csv` — параметры экспериментов.
- `results/runs.csv` — результаты всех независимых запусков.
- `results/summary.csv` — итоговая статистика по методам.
- `results/examples.csv` — примеры допустимых и недопустимых расписаний.
- `results/best_schedule.csv` — лучшее расписание в табличном виде.
- `results/best_schedule.txt` — то же расписание в человекочитаемом виде по дням и слотам.
- `figures/` — графики экспериментов и блок-схема алгоритма.

## Что реализовано

Особь представляется вектором из 24 целых чисел. Каждое число — номер временного слота для соответствующего экзамена.

В алгоритме используются:

- турнирная селекция;
- равномерный и одноточечный кроссоверы;
- мутация заменой временного слота;
- элитизм;
- два способа работы с ограничениями: штраф и repair;
- разделение жёстких конфликтов и мягких штрафов.

Дополнительно алгоритм сравнивается с простой случайной конструктивной эвристикой.

## Параметры

- число экзаменов: 24;
- число студентов: 160;
- число временных слотов: 10;
- размер популяции: 30;
- бюджет: 300 оценок целевой функции на один запуск;
- размер турнира: 3;
- вероятность кроссовера: 0.90;
- вероятность мутации одного гена: 0.08;
- элитизм: 2 особи;
- число независимых запусков: 20;
- seed серии запусков: `202600`–`202619`;
- seed генерации данных: `202619`.

## Установка

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

## Как запускать

Обычный одиночный запуск генетического алгоритма:

```bash
python ga_schedule.py
```

Полный эксперимент с 20 запусками, сравнением методов, CSV и графиками:

```bash
python experiments.py
```

Если нужно заново сгенерировать входные данные с тем же seed:

```bash
python generate_data.py
```

После `experiments.py` результаты сохраняются в папки `results/` и `figures/`.

## Что сравнивается в экспериментах

1. `penalty_uniform` и `repair_uniform` — штрафы против восстановления допустимости при одинаковом равномерном кроссовере.
2. `repair_uniform` и `repair_one_point` — равномерный и одноточечный кроссоверы при одинаковом repair.
3. `repair_uniform` и `random_baseline` — генетический алгоритм против простой конструктивной эвристики при одинаковом числе итоговых оценок расписаний: 300 на запуск. При этом вычислительные затраты на построение одного расписания у методов могут различаться.

Основной результат: repair получил допустимое расписание во всех 20 запусках. Лучшее найденное расписание не содержит жёстких конфликтов и имеет мягкий штраф `97.5`.
